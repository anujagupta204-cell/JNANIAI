# Jnana AI - AI-Powered Chat Application

A premium AI-powered chat application using Gemini AI with a stunning, responsive UI featuring glassmorphism design, dark/light themes, and device auto-detection.

## Features

- 🤖 **AI-Powered Conversations** - Powered by Google's Gemini AI
- 🎨 **Premium UI** - Modern glassmorphism design with smooth animations
- 🌓 **Dark/Light Themes** - Toggle between beautiful dark and light modes
- 📱 **Responsive Design** - Auto-detects and adapts to Mobile, Tablet, Laptop, and Desktop
- 💾 **Chat History** - Saves your conversations locally
- 🎭 **Animated Crystal Ball** - Dynamic background with animated crystal ball
- 🔊 **Voice Greeting** - Welcome message with text-to-speech

## Tech Stack

- **Frontend**: HTML5, CSS3 (Glassmorphism), Vanilla JavaScript
- **Backend**: Node.js, Express
- **AI**: Google Gemini API
- **Fonts**: Google Fonts (Inter, Outfit)

## Installation

1. Clone the repository:
```bash
git clone <your-repo-url>
cd p
```

2. Install dependencies:
```bash
npm install
```

3. Create a `.env` file in the root directory:
```bash
cp .env.example .env
```

4. Add your Gemini API key to `.env`:
```
GEMINI_API_KEY=your_actual_api_key_here
PORT=3000
```

## Usage

1. Start the server:
```bash
npm start
```

2. Open your browser and navigate to:
```
http://localhost:3000
```

3. Start chatting with Jnana AI!
