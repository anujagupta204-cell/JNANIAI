# Jnana AI - Offline AI Chat Application

A premium, offline AI-powered chat application that provides future insights using a local knowledge base. Featuring a stunning, responsive UI with glassmorphism design, dark/light themes, and device auto-detection.

## Features

- 🤖 **Offline Conversations** - Powered by a local searchable dataset
- 🎨 **Premium UI** - Modern glassmorphism design with smooth animations
- 🌓 **Dark/Light Themes** - Toggle between beautiful dark and light modes
- 📱 **Responsive Design** - Auto-detects and adapts to Mobile, Tablet, Laptop, and Desktop
- 💾 **Chat History** - Saves your conversations locally
- 🎭 **Animated Crystal Ball** - Dynamic background with animated crystal ball
- 🔊 **Voice Greeting** - Welcome message with text-to-speech

## Tech Stack

- **Frontend**: HTML5, CSS3 (Glassmorphism), Vanilla JavaScript
- **Backend**: Node.js, Express
- **Dataset**: Local JSON knowledge base
- **Fonts**: Google Fonts (Inter, Outfit)

## Installation

1. Clone the repository:
```bash
git clone <your-repo-url>
cd p
```

2. Install dependencies:
```bash
npm install
```

3. Start the server:
```bash
npm start
```

## Usage

1. Open your browser and navigate to:
```
http://localhost:3000
```

2. Start chatting with Jnana AI!

```
p/
```

This application searches through `chat_data.json` to provide answers. You can expand the knowledge base by adding more entries to this file.
